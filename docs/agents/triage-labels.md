# Triage labels

Use these exact values in each ticket's Status field:

| Status | Meaning |
| --- | --- |
| needs-triage | Needs evaluation |
| needs-info | Waiting for more information |
| ready-for-agent | Fully specified for agent implementation |
| ready-for-human | Requires human implementation |
| wontfix | Will not be implemented |
| complete | Implemented, validated, and reviewed; record any validation limitations in the ticket |
